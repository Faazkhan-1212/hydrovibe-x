# HYDROVIBE - X

An early website for the proposed algae-based autonomous water purification drone.

## Homepage

The opening scene uses the supplied aerofoil concept artwork, cropped to focus on the drone and lake. CSS adds a slow floating motion, water shimmer, wakes, and moving particles to suggest water flow through the proposed treatment system. Across the page, layered underwater caustics and current lines shift at different rates with scrolling for a restrained parallax depth effect. The artwork and effects are a visualization; they do not demonstrate or guarantee purification performance.

## Files

- `index.html` — responsive landing page and treatment path
- `styles.css` — layout, water scene, motion, and responsive styles
- `script.js` — lightweight pointer and scroll depth cues; respects reduced-motion preferences
- `assets/` — supplied HYDROVIBE-X concept references
- `assets/hydrovibe-x-official-logo.png` — official website logo supplied by the project owner

## Preview

Open `index.html` in a modern browser. No build step or package install is required.

The supplied domain `hydrovibe-x.com` still needs DNS and hosting configuration before it can serve this site.
